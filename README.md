How Many Tabs Do You Have Open? — a program that writes one honest tab count to `entry.txt`: **1**. Not a hoarder's number. One tab — the closer who shuts every tab the moment they are done with it, the lowest count that is still unambiguously a browser someone is sitting in front of. Far lower than the field would guess, believable, and a whole habit in a single digit.

## Run it

```sh
node main.ts
```

Writes the count to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic: the same single digit on every run.
